# Lab 04 - OSPF Dynamic Routing

## Objective
Configure OSPF (Open Shortest Path First) dynamic routing between two routers to allow communication between separate LAN networks.

## Network Overview
This lab contains:
- Two routers
- Two switches
- Four PCs
- Two LAN networks
- One point-to-point network connecting the routers

## Networks
- LAN A: 192.168.10.0/24
- Router-to-Router Network: 10.0.0.0/30
- LAN B: 192.168.20.0/24

## Skills Demonstrated
- IPv4 addressing
- Router interface configuration
- OSPF configuration
- OSPF neighbor establishment
- Dynamic route advertisement
- Routing table verification
- End-to-end connectivity testing
- Network troubleshooting

## Verification
OSPF was successfully configured between the routers. The routers established an OSPF neighbor relationship and dynamically learned the remote networks.

End-to-end connectivity between the LANs was successfully verified.
