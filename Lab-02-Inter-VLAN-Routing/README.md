# Lab 02 - Inter-VLAN Routing

## Objective
Configure Inter-VLAN routing using a router-on-a-stick configuration to allow devices in different VLANs to communicate with each other.

## Skills Demonstrated
- Creating and configuring VLANs
- Assigning switch ports to VLANs
- Configuring an 802.1Q trunk link
- Configuring router subinterfaces
- Configuring default gateways
- Routing traffic between VLANs
- Testing and verifying network connectivity

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Lab Topology
This lab uses a Cisco router connected to a switch containing multiple VLANs. PCs are assigned to separate VLANs representing different departments, including HR, Sales, and IT.

## Verification
Inter-VLAN connectivity was tested in Cisco Packet Tracer to verify that devices in different VLANs could successfully communicate through the router.
