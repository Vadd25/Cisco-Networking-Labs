# Lab 03 - Static Routing

## Objective
Configure static routing between two separate LANs so devices on both networks can communicate through two routers.

## Network Overview
This lab contains:
- Two routers
- Two switches
- Four PCs
- Two LAN networks
- One point-to-point network between the routers

## Networks
- LAN 1: 192.168.10.0/24
- Router-to-Router Network: 10.0.0.0/30
- LAN 2: 192.168.20.0/24

## Skills Demonstrated
- IPv4 addressing
- Router interface configuration
- Static route configuration
- Routing table verification
- End-to-end connectivity testing
- Network troubleshooting

## Verification
Connectivity between the two LANs was successfully tested after configuring static routes on both routers.
