# Lab 01 - VLANs and Trunking

## Objective
Configure VLANs and trunking between Cisco switches to separate network traffic while allowing VLAN traffic to pass between switches.

## Skills Demonstrated
- Creating and configuring VLANs
- Assigning switch ports to VLANs
- Configuring trunk links
- Verifying VLAN and trunk configurations
- Testing network connectivity

## Tools Used
- Cisco Packet Tracer
- Cisco IOS CLI

## Lab Topology
This lab uses two Cisco switches connected by a trunk link, with multiple PCs assigned to different VLANs.

## Verification
The network configuration was tested in Cisco Packet Tracer to verify VLAN membership, trunk operation, and connectivity.
