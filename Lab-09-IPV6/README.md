# Lab 09 – IPv6 Networking

## Objective
Configure and verify IPv6 addressing and connectivity in a Cisco network using Cisco Packet Tracer.

## Network Overview
This lab demonstrates the implementation of IPv6 addressing on Cisco network devices and end hosts.

IPv6 addresses were configured on the appropriate router interfaces and hosts to establish communication across the network.

## Configuration
The network devices were configured with IPv6 addressing and the required routing settings.

The configuration included:

- IPv6 addressing
- IPv6 router interface configuration
- Enabling IPv6 routing
- IPv6 default gateway configuration
- End-device IPv6 configuration
- IPv6 connectivity testing

## Verification
IPv6 connectivity was tested between network devices to verify that the configuration was functioning correctly.

Ping and Cisco IOS verification commands were used to confirm successful IPv6 communication.

## Skills Demonstrated
- IPv6 addressing
- IPv6 network configuration
- Cisco router configuration
- IPv6 routing
- IPv6 connectivity testing
- Network troubleshooting
- Cisco IOS CLI
- Cisco Packet Tracer
