# Lab 05 – DHCP Configuration

## Overview

This lab demonstrates the configuration of DHCP in a Cisco Packet Tracer network. DHCP is used to automatically provide hosts with IP addressing information, reducing the need for manual IP configuration.

## Objectives

- Configure DHCP for network hosts
- Automatically assign IP addresses to client devices
- Configure default gateway information
- Verify DHCP address assignment
- Test connectivity between network devices

## Network Topology

The lab consists of two LANs connected through Cisco routers. Each LAN contains end devices connected through a switch.

![DHCP Network Topology](Screenshots/CCNA%20LAB%205%20DHCP.png)

## Technologies Used

- Cisco Packet Tracer
- DHCP
- IPv4 Addressing
- Routing
- Cisco IOS

## Verification

DHCP operation was verified by confirming that client devices successfully received IP configuration and could communicate across the network.
