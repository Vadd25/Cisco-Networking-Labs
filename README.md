# Cisco Networking Labs | CCNA Portfolio

Hands-on networking portfolio built in Cisco Packet Tracer while developing practical Cisco networking and CCNA-level skills.

## About This Portfolio

This repository contains 10 hands-on networking labs covering switching, routing, network services, security, IPv6, and enterprise network design.

Each lab includes a Cisco Packet Tracer file, documentation, and screenshots demonstrating configuration and verification.

## Technical Skills

- VLANs and 802.1Q Trunking
- Inter-VLAN Routing
- Static Routing
- OSPF Dynamic Routing
- DHCP
- NAT/PAT
- Standard and Extended ACLs
- SSH Secure Remote Management
- Switch Port Security
- IPv6 Addressing and Routing
- Cisco IOS CLI
- Network Connectivity Testing and Troubleshooting

## Projects

### Lab 01 — VLANs and Trunking
Configured VLAN segmentation and 802.1Q trunk links between Cisco switches.

### Lab 02 — Inter-VLAN Routing
Configured routing between VLANs to enable communication across separate broadcast domains.

### Lab 03 — Static Routing
Implemented static routes between multiple networks and verified end-to-end connectivity.

### Lab 04 — OSPF Dynamic Routing
Configured OSPF to dynamically exchange routing information between routers.

### Lab 05 — DHCP
Configured DHCP services to automatically provide IP addressing information to network clients.

### Lab 06 — NAT/PAT
Configured Network Address Translation and PAT to translate private internal addresses for external connectivity.

### Lab 07 — Access Control Lists
Implemented ACLs to permit and deny network traffic according to defined security requirements.

### Lab 08 — SSH Secure Management
Configured secure SSH remote administration and switch port security.

### Lab 09 — IPv6
Configured IPv6 addressing and routing and verified IPv6 connectivity between networks.

### Lab 10 — Small Enterprise Network
Designed and configured an integrated enterprise network combining VLANs, trunking, inter-VLAN routing, DHCP, ACLs, SSH, and port security.
