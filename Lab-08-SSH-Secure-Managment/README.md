# Lab 08 – SSH Secure Remote Management

## Objective
Configure secure remote access to a Cisco network device using SSH.

## Network Overview
This lab demonstrates how SSH can be used to securely manage Cisco network devices remotely through the command-line interface.

## Configuration
The Cisco device was configured for SSH remote access.

The configuration included:

- Device hostname configuration
- Domain name configuration
- Local username and password authentication
- RSA key generation
- SSH configuration
- VTY line configuration
- Remote login authentication

## Verification
SSH connectivity was tested from a network host to verify that remote management was functioning correctly.

A successful SSH login confirmed that the device could be securely accessed remotely.

## Skills Demonstrated
- SSH configuration
- Secure remote device management
- RSA key generation
- Local user authentication
- VTY line configuration
- Cisco IOS CLI
- Network connectivity testing
- Cisco Packet Tracer
